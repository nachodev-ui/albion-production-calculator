# Cuentas y acceso

La guía técnica completa vive en [Arquitectura de cuentas, autenticación y entitlements](./architecture/accounts-access.md).

El Hito 2 integra Auth0 en la SPA, sincroniza `/api/v1/me`, conserva el acceso efectivo en Zustand y bloquea capacidades Pro mediante entitlements resueltos por la API central.
